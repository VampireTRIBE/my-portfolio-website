ABOUT ME

I am Shaikh Amir Hussain, a Full Stack MERN Developer and Computer Science graduate from Jamia Hamdard University. I specialize in building responsive web applications using MongoDB, Express.js, React.js, and Node.js, with a strong emphasis on clean code architecture, user authentication, and seamless database integration.

My core skills include modern frontend development with HTML5, CSS3, JavaScript (ES6+), and React.js (Hooks, Context API), as well as backend API design and server-side logic using Node.js and Express.js. I have practical experience managing databases in MongoDB, implementing CRUD functionality, and optimizing performance for dynamic applications.

Among my projects, Adventure Express stands out as an Airbnb-inspired platform featuring secure user authentication with Passport.js, dynamic itinerary planning, and a fully responsive UI. Additionally, I’ve developed interactive games like Simon Game and Tic-Tac-Toe, demonstrating my proficiency in complex algorithms and interactive interface design.

Beyond coding, I enjoy motorcycle adventures and cultural explorations that fuel my creativity and adaptability. I’m passionate about leveraging technology to solve real-world problems and thrive in collaborative environments that encourage continuous learning and innovation.
